# 知识库与分析 Agent 运行规则

## 文档支持
知识库支持上传 Markdown、PDF 和 DOCX 文档。加载器只提取文本和标题或页码位置，不执行文档中的脚本或嵌入内容。

## 重复文档
系统根据文件字节的 SHA256 检测重复文档。同一内容再次上传会返回已有文档记录，避免重复切分和重复索引。

## 稳定知识块
文档会按章节和句子切分为知识块。知识块 ID 由稳定 document_id、原始位置、块序号和文本共同计算，方便评测题长期关联同一证据。

## 混合检索
混合检索同时使用 BGE 向量语义检索和 BM25 关键词检索，再通过加权倒数排名融合 RRF 合并结果。向量检索擅长语义相近表达，BM25 擅长精确术语和编号。

## 来源引用
知识问答把检索证据标记为 S1、S2 等来源，回答中的引用必须能映射回实际知识块。无法解析或引用未知标签时，系统拒绝把答案当成有效结果。

## 证据不足
如果没有检索结果、证据得分不满足条件，或回答模型主动判断资料不足，系统返回“现有资料不足以回答该问题”，而不是编造答案。

## Agent 工具
当前 Agent 有知识问答、交通预测和模型指标三个主要工具。规则路由会根据问题意图选择工具；同时涉及预测与指标的问题可以进入 combined 流程。

## 预测服务降级
知识库 API 与交通预测服务是独立进程。预测服务不可用时，健康状态显示 forecast=false，知识检索和文档管理仍可工作，预测相关回答会显示局部错误。

## 检索评测
检索评测使用 Hit@1、Hit@3、Recall@K 和 MRR。向量、BM25 和混合策略必须使用相同语料快照、相同问题及相同人工相关性标注，才能公平比较。

## 运行安全边界
项目默认只使用项目目录内的数据、索引和模型，不应扫描其他用户文件。共享服务器上不使用 systemctl 重启系统服务，GPU 任务必须先检查空闲资源。
